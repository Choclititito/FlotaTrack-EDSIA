# ADR-0001 Arquitectura en capas, comunicacion con ESP32

## Estado
Aceptado 

## Contexto
Necesitabamos poder crear una forma de comunicacion entre el vehiculo con sus datos y el gerente que va a revisar los datos del camion y del viaje, asi como poder activar una señal para desactivar la unidad a distancia.  
El equipo de trabajo se compone de 2 personas, con 3 semanas para trabajar en esto, y con un presupuesto limitado.

## Decisión
Se utilizara una API creada por capas (routers, services, repositories, models).  
Para la comunicacion a distancia se usara un ESP32


## Alternativas consideradas
Utilizar otro microcontrolador como puede ser el Arduino UNO, o una Rasberry pi, entre otros, lo cual no se podria ser por el presupuesto que se tiene, ademas de la facilidad que da el Esp32 con algunas funciones.

## Consecuencias
En lo que mas nos ayuda esta decision es ya conocer el hardware y tenerlo en inventario, y las mayores consecuencias es que nos limitamos a lo que este microcontrolador nos ofrece y tener que limitar actualizaciones futuras
